# 루트 정리 (워크스페이스 인덱스)

아이폰 앱이 워크스페이스를 한꺼번에 찾도록 `<루트>/.clipment/index.json` 을 만든다 (SPEC §9).

## 안전 규칙
- **아무것도 삭제하지 않는다.** 폴더·파일 이동/이름 변경도 사용자의 명시적 확인 없이 하지 않는다.
- `workspace.json` 생성(`--fix`)은 사용자가 확인한 뒤에만.

## 순서
1. 루트 경로를 사용자에게 묻고 확인한다 (예: `~/Library/Mobile Documents/com~apple~CloudDocs/Clipment`). 추측하지 않는다.
2. `index_root`(root) 또는 `clipment index <루트>` 를 실행한다. 깊이가 모자라면 `--depth N`.
3. 결과를 보고한다: 찾은 워크스페이스(경로·이름·프로젝트 수), 인덱스 파일 위치.
4. `workspace.json` 이 없는 워크스페이스가 있으면 알려 주고, **확인을 받은 뒤** `clipment index <루트> --fix` 를 실행한다.
5. 워크스페이스 밖에 흩어진 프로젝트 폴더(`project.json` 이 있는데 어떤 워크스페이스에도 속하지 않는 것)가 보이면 어느 워크스페이스로 옮길지 **제안만** 한다. 사용자가 명시적으로 승인한 폴더만 옮기고, 옮긴 뒤 `clipment index <루트>` 를 다시 실행한다.
